# Ionic Vue Unit Testing (Vuex Version) - Blueprint

## Tech Stack
- **Framework:** Ionic Vue (Vue 3)
- **Testing:** Jest + Vue Test Utils
- **State Management:** Vuex 4 (Modules)
- **Networking:** Axios

## Testing Standards
1. **Mocking**
   - Mock `@ionic/vue` controllers (Modal, Toast, Loading) immediately.
   - Mock Capacitor Plugins and API Services.
2. **Vuex**
   - Test Mutations as Pure Functions.
   - Test Actions by mocking `commit` and API.
   - In Components use `createStore` to create Mock Store.
3. **Ionic Lifecycle**: Test code in `ionViewDidEnter` and `ionViewWillLeave` by calling via `wrapper.vm`.
4. **Target**: Coverage 80%+; focus on logic inside Store and Services.

## Learning Phases
- **Phase 1: Utils** – Pure calculation and formatting functions.
- **Phase 2: Vuex Store** – Separate tests for Mutations, Actions, and Getters.
- **Phase 3: Services** – API and Capacitor Plugins handling.
- **Phase 4: Components & Pages** – Rendering and dispatching actions.
